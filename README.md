# Algorithm Simulation

A C# Windows Forms learning application for visualizing data structures and algorithms. The source contains forms for sorting, stacks, queues, linked lists, and hash sets, along with the original icon artwork.

![Original stack icon artwork](ALGO%20ICONS/ALGO/7.jpg)

## Stack

C#, Windows Forms, .NET Framework 4.7.2.

## Run locally

Open `ALGO_SIMULATION.sln` in Visual Studio on Windows, restore any required framework components, then build and run the application.
